# مغامرة قطرة الماء: رحلة لا تنتهي! 💧

موقع تعليمي عربي تفاعلي لطلبة الصفوف الثالث إلى الخامس عن دورة المياه في الطبيعة.

## محتويات المشروع

- ترحيب بشخصية ندى وحفظ اسم الطالب محلياً.
- محاكاة إنفوجرافيك ثلاثية الأبعاد للمراحل الخمس: التبخر، النتح، التكاثف، الهطول، والتجمع.
- تحكم مستقل بحرارة الماء والسماء، وتجارب إزالة الأشجار والثلج.
- خمس ألعاب، مع تعزيز الإجابة الصحيحة وتلميحات للمحاولة التالية.
- مكتبة إنفوجرافيك قابلة للتكبير والتحميل.
- جواز مستكشف وخمس جزر وهدايا معرفية وحديقة رقمية في ختام الرحلة.
- شهادة PNG باسم الطالب.

## التشغيل محلياً

فك ضغط الملف، ثم افتح `index.html` في متصفح حديث. إذا منع المتصفح بعض الميزات من الملفات المحلية، شغّل الخادم البسيط أدناه. يحتاج الخط العربي الخارجي إلى الإنترنت؛ يوجد خط بديل عند عدم الاتصال.

المشروع موقع ثابت مبني باستخدام HTML وCSS وJavaScript؛ لا يحتاج إلى تثبيت حزم أو بناء.

```sh
python3 -m http.server 8000
```

افتح http://localhost:8000 في المتصفح. انقر داخل الموقع لبدء الصوت؛ قد يمنع المتصفح التشغيل التلقائي قبل التفاعل.

## الملفات

`index.html` هو نقطة البداية. ملفات JavaScript تنفذ بالترتيب المحدد داخله. مجلد `assets/` يتضمن الصور والتعليق الصوتي والمؤثرات الصوتية المستخدمة محلياً.

## الخصوصية والتبعيات

اسم الطالب والتقدم محفوظان في localStorage على المتصفح، دون قاعدة بيانات أو خادم للموقع. يستخدم الموقع Google Fonts لتحميل الخط العربي؛ الصور والأصوات موجودة ضمن المشروع.

التعليق العربي مولد بالذكاء الاصطناعي. المحاكاة نموذج تعليمي مبسط، وليست تنبؤاً بالطقس. صور البخار المضيئة رموز توضيحية؛ بخار الماء الحقيقي غير مرئي.

## النشر
